# FoodBridge

A Community Food Surplus and Donation Matching System
Computer Science 2 - Quarter 1 Project Proposal

## About
FoodBridge is a proposed system that connects people and small businesses
with surplus, still-edible food to nearby individuals or organizations who
need it, before it gets thrown away. It also includes partner drop-off
points (like a barangay hall or community center) for recipients who don't
have a phone or app access, so the system isn't only usable by people with
smartphones.

This repo is for the Quarter 1 proposal stage only. No working program is
included yet - this covers the problem, objectives, features,
inputs/outputs, and the pseudocode logic plan.
